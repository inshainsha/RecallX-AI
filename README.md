# RecallX-AI
An AI-Powered Android app for Searching gallery images, screenshot, PDFs, receipts and documents.

#Search Anything. Find It Faster.
### An AI-Powered Unified Search System for Images and Documents.

## WHAT IS RecallX-AI?

RecallX-AI is an Android app idea that will help users find their gallery photos, screenshots, PDFs, receipts, and other documents in one place.

## WHY ARE WE BUILDING IT?

Sometimes we have so many photos and files on our phones that finding one particular file becomes difficult. We may also forget its name or where we saved it. We want to make this process easier and save users' time.

## HOW WILL IT WORK?

1. The app will access supported gallery images after getting permission from the user.
2. Users will be able to select PDFs and other documents they want to search.
3. OCR will help the app read text written inside images and supported scanned documents.
4. The app will save searchable text and file details in a local database.
5. Users will be able to search for files using keywords.
6. We also plan to add AI-based visual search so users can find images by describing what they remember.

## KEY FEATURES

- Search photos, screenshots, and documents in one place
- Find text inside images using OCR
- Search supported PDFs and receipts
- AI-based visual search (planned)
- Store searchable file details locally

## TECHNOLOGIES WE PLAN TO USE

- Java
- XML
- Android Studio
- Google ML Kit for text recognition
- SQLite / Room database

## PROJECT STATUS

We are currently in the planning and initial development stage.

## OUR GOAL

Our goal is to make finding photos and documents easier, even when users do not remember their exact names.
